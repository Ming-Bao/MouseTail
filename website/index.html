Private

Stays on
your network.

Your keystrokes go straight to the computer beside you and nowhere else.

  • Encrypted end to end

    Every connection uses TLS 1.3, with keys that never leave each computer.

  • No account, no cloud

    Nothing to sign up for. MouseTail only ever talks to your own computers.

  • Paired with a code

    The code never crosses the network, and wrong guesses lock pairing for a while.

  1. While a password field has Secure Input on, macOS keeps the keyboard to itself. MouseTail tells you when that happens.
  2. Run enable-input.sh once (it asks for your password) so other computers can type and click here. The installer tells you when.
  3. GNOME doesn't let background apps use the clipboard yet.
  4. Needs the System Audio Recording permission.
  5. When KDE or GNOME is the computer playing, it needs the enable-input.sh setup to take the presses.
  6. Run enable-wake.sh once. Needs NetworkManager and a network card that can be woken.
  7. Omarchy only. Plain Hyprland uses the command line.
  8. If your desktop doesn't start systemd's graphical session (Hyprland or Sway without uwsm, say), add one line to its config. The installer shows you which.

Linux means Wayland desktops with systemd and PipeWire. Keys are sent by position, so give both computers the same keyboard layout. Using something else? Tell us how it goes
